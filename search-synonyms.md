# Search Synonyms

Search synonyms tell storefront search that different words mean the same thing, so a search for "trainers" can find a product titled "Sneakers".

Open **Products > Search synonyms**.

## Adding a search synonym

Click **Add search synonym**, or click a row to edit.

- **Two-way**: every term is equal. Searching any of them also finds the others. Use this when the words mean the same thing: sneakers, trainers, kicks.
- **One-way**: searching the query also finds the synonyms; searching a synonym does not find the query. Use this for informal or broader words: cheap → affordable, budget.
- **Active**: uncheck to stop using it without deleting it.

A word or phrase can only be used in one search synonym.

## On the storefront

Active search synonyms apply to shop search, search suggestions, and the filters next to results. What the customer typed is still what [Top searches](/reports) records.

Zero-result queries in that report are the best source of new synonyms.

## Deleting

Select the ones you want gone and click **Delete**. Deletion is permanent.
