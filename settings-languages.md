# Language Settings

Control what language your store uses and which others you offer, under **Settings > Language**.

## Default Language

The language your store falls back to for anyone who hasn't chosen otherwise. Pick it from the dropdown, which lists every language installed on your store.

## Available Languages

Check each language you want to offer visitors. The default language is always enabled and can't be unchecked.

With more than one language enabled, a language switcher appears on your storefront. With only one, it stays hidden.

Click **Save changes** to apply.

## Translating Content

Enabling a language makes it selectable, but it doesn't translate anything for you. Products, categories, pages, and other content each need translations entered in the admin panel. Anything without a translation falls back to the default language version.
