# Translating Content

With multiple languages enabled, you can translate your content so customers see product titles, descriptions, and more in their own language. It's all done from the admin panel, with no extra tools or plugins.

## How Translations Work

1. Use the language switcher in the top-right corner of the admin panel to pick the language you're translating into.
2. Open the product, category, or other item. Its translatable fields now show that language, pre-filled with the default language text as a starting point.
3. Enter the translations and save.

Customers browsing in that language see the translated content. Anything you haven't translated falls back to the default language version.

::: tip
The language switcher only appears once you have two or more languages enabled. Add them under **Settings > Language**.
:::

## What Can Be Translated

Only text-based content that customers see. Prices, SKUs, images, and stock levels are shared across every language.

- **Products**: title, description, SEO title, SEO description
    - **Variants**: variant title
    - **Options**: option name and values
- **Categories**: name and description
- **Brands**: name and description
- **Blog posts**: title, excerpt, content
- **Flash sales**: title and description
- **Shipping**: carrier name, rate name, rate delivery time
- **Payments**: gateway name
- **Taxes**: tax rate name
- **Regions**: region name
- **Store settings**: store description (the footer tagline)

**Storefront** covers homepage section titles, navigation menu labels in the header and footer, announcement bar content, and the content of each section type:

- **Hero Slider**: each slide's headline, subtext, and button text, and each side tile's title and subtitle
- **Info Strip**: each item's title and subtitle
- **Category Grid**: each category's name
- **Deal of the Day**: subtitle
- **Product Tabs**: each tab's label
- **Promo Banners**: each banner's title and subtitle
- **Product Columns**: each column's heading
- **Testimonials**: each quote and author name
- **Newsletter**: subtitle and button text

## Tips

- Switch back to your default language when you're done so you can manage the store as usual.
- Each resource saves independently, so translating a product doesn't touch its categories or anything else related.
- Missing translations show the original rather than an empty value, so partial translation is perfectly safe.
